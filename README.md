# portal-shijiebei2026-pages

## 项目简介

本仓库用于归档和发布多个独立的 HTML 页面。这些页面以静态文件的形式存放，不依赖特定后端服务，可直接通过浏览器访问。仓库主要服务于个人或小范围使用的页面资源管理与分发场景。

## 目录说明

```
├── README.md        # 本文件
├── index.html       # 仓库首页 / 导航页（可选）
├── pages/           # 存放独立 HTML 页面的目录
│   ├── example1.html
│   ├── example2.html
│   └── ...
└── assets/          # 页面共用资源（图片、样式、脚本等）
    ├── css/
    ├── js/
    └── images/
```

- `pages/`：每个 HTML 文件对应一个独立页面，文件名即页面标识。
- `assets/`：存放页面所需的公共资源，按类型分目录组织。

## 页面归档说明

- 本仓库内的 HTML 页面均为独立功能单元，相互之间无强依赖关系。
- 每个页面可包含自己的样式与脚本，也可引用 `assets/` 下的公共资源。
- 归档的页面可能随需求更新、替换或移除，不保证永久保留所有历史版本。
- 建议在 `pages/` 下为每个页面添加简短说明注释，方便后续维护。

## 使用方式

1. 克隆仓库到本地：
   ```bash
   git clone https://github.com/your-username/portal-shijiebei2026-pages.git
   ```
2. 直接在浏览器中打开 `index.html` 或 `pages/` 下的任意 HTML 文件即可查看。
3. 若需部署到静态托管服务，可将整个仓库内容上传至服务根目录。

## 维护说明

- 新增页面：在 `pages/` 下创建新的 HTML 文件，并确保其内部资源引用路径正确。
- 更新页面：直接修改对应 HTML 文件内容，建议在文件头部注明修改日期与说明。
- 删除页面：移除 `pages/` 下对应文件，并检查是否有其他页面引用该文件。
- 公共资源：修改 `assets/` 下文件时，请同步更新所有引用该资源的页面。
- 提交规范：建议使用简洁的 commit message，如“新增页面：xxx”、“更新页面：xxx 样式调整”等。

## 注意事项

- 本仓库仅用于静态页面归档与展示，不包含任何动态功能（如数据库、用户认证等）。
- 页面内容请遵守相关法律法规及 GitHub 服务条款。
- 仓库维护者保留对内容进行管理、调整或删除的权利。
